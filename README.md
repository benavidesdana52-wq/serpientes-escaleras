# 🐍 Serpientes y Escaleras Moderno

¡Juego clásico de Serpientes y Escaleras en HTML, CSS y JavaScript!

## 🎮 Características

- ✅ Tablero de 10x10 casillas
- ✅ 2 jugadores (Rojo y Azul)
- ✅ Serpientes y Escaleras distribuidas
- ✅ Dado interactivo
- ✅ Interfaz moderna con gradientes
- ✅ Animaciones suaves
- ✅ Responsive

## 🚀 Cómo jugar

1. Abre `index.html` en tu navegador
2. Presiona el dado para lanzarlo
3. Tu ficha avanzará automáticamente
4. Si caes en una serpiente, bajas
5. Si caes en una escalera, subes
6. ¡El primero en llegar a 100 gana!

## 📁 Archivos

- `index.html` - Estructura del juego
- `style.css` - Estilos y diseño
- `script.js` - Lógica del juego
